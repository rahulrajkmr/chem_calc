How to Push to GitHub & Deploy

This calculator is compiled into a single clean file (index.html). You can host it online completely free in under 2 minutes using GitHub Pages or Vercel:

  1. Create a new public repository on GitHub.
  2. Save this code locally as index.html.
  3. Run in your project folder:
    git init
    git add index.html
    git commit -m "Initial commit: Galvanic cell calculator"
    git branch -M main
    git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
    git push -u origin main
  4. Go to your GitHub Repository Settings > Pages, select source branch as main, and save! Your calculator will be live instantly.
